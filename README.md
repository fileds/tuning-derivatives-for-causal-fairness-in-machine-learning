# Tuning Derivatives for Causal Fairness in Machine Learning
Repo with example code and code to reproduce the simulation study in "Tuning Derivatives for Causal Fairness in Machine Learning", published in Machine Learning (Springer) on 18 May 2026 ([https://link.springer.com/article/10.1007/s10994-026-07061-7](https://link.springer.com/article/10.1007/s10994-026-07061-7)). To cite: Edström, F., Barros, G.W.F., Gorbach, T. de Luna, X. Tuning Derivatives for Causal Fairness in Machine Learning. Mach Learn 115, 126 (2026). https://doi.org/10.1007/s10994-026-07061-7

Explore the MWE in [fair_tuning_mwe.ipynb](fair_tuning_mwe.ipynb) notebook or look at the fair tuning implementation in [fair_tuning.py](fair_tuning.py). To reproduce simulations or run fair tuning on your own, clone the repo and run `pip install -r requirements.txt` in your virtual environment. 

For more information, contact the corresponding author by following the link to the publication above.
